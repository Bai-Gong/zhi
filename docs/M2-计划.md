## 1. 范围

**做**：全文搜索、批注高亮（查看 + 新建 + 另存副本）、阅读模式（沉浸 + 深色）、键盘快捷键体系、多标签文档。

**不做**（推至后续）：高亮跨会话持久化（M2 高亮仅会话内有效，导出走「另存副本」）、批注导出为注释对象（pdf-lib 只画矩形）、OCR 搜索（后置能力清单）。

## 2. 设计走查结论（关键决策）

| # | 决策 | 要点 |
| --- | --- | --- |
| D1 | store 从单会话改多标签 | `tabs: TabSession[]` + `activeTabId`。每标签独立持有：路径、页码、缩放、pdf.js 文档、文本索引、高亮集。打开新文件 = 新标签（上限 8 个，超出提示）。关闭标签 = `page.cleanup()` + `document.destroy()` 释放内存 |
| D2 | 标签条 UI 归 viewer 模块 | 消费 core store，渲染在查看器顶栏上方；shell 四区布局不动（边界规则 4.3.2 不破） |
| D3 | 文本索引归 core/document | 新增 `textIndex.ts`：逐页 `getTextContent`（文本 + 变换坐标），懒构建、时间切片、可取消、带进度。`pdfjs-dist` 仍只在 core 内 import（规则 4.3.1） |
| D4 | 搜索结果面板放查看器主区右侧 | viewer 内部布局（可折叠栏），不动 shell 的右侧面板占位（留给 M5 属性面板） |
| D5 | 高亮三层模型 | 选区 → 页内矩形（与画布/文本层同 viewport 换算，技术方案 5.2 第 8 条）→ 高亮对象 `{页码, 矩形组, 颜色}`。查看态 = 覆盖层 div；导出 = pdf-lib 半透明矩形写入用户选定的**副本**，原文件字节不动 |
| D6 | UI 偏好 store 落 shell | 新增 `src/shell/uiStore.ts`：主题（浅/深/跟随系统）、沉浸模式、侧栏折叠、搜索面板开合。符合规则 4.3.5「store 只在 core/document 与 shell 两处」 |
| D7 | 快捷键归 shell 统一注册 | 新增 `src/shell/hotkeys.ts`，单点 keydown 分发到 core store / uiStore；避开系统与浏览器保留组合 |
| D8 | 深色模式走 CSS 变量 | `theme.css` 补深色色板；文档画布可选反色滤镜（设置项，**默认关**，大页性能风险） |

**需同步回改《技术方案.md》**（本文落地时一并修订）：4.1 模块职责表——模块 1 增 uiStore/hotkeys，模块 3 增标签条/搜索面板/高亮覆盖层，模块 5 增多标签会话/文本索引/高亮导出。

## 4. 验收补充（里程碑 M2 条目的执行口径）

测试物料提前准备：500 页纯文本 PDF（自造，含中文）、含多级书签 PDF、含既有高亮批注的 PDF（Acrobat 制作）、Windows 参考机型。

1. 搜索性能（M2-1）：500 页 ≤5 秒出全量结果，进度可见；点击结果跳页滚动到位、命中矩形闪烁。
2. 搜索开关（M2-2）：大小写敏感/不敏感、当前页/全文档两个开关各验证一次。
3. 高亮（M2-3）：选中着色贴合；≥3 种颜色；另存副本后 Chrome 与 Acrobat 双端目检高亮一致；原文件哈希不变。
4. 阅读模式（M2-4）：沉浸模式边缘唤出/还原；深色下全组件对比度可读；画布反色滤镜开/关各看一次。
5. 快捷键（M2-5）：打开/关闭/搜索/缩放/翻页/阅读模式逐个触发，与系统输入法/浏览器无冲突。
6. 多标签（M2-6）：3 个文档并存切换，页码缩放各自保持；关 1 个标签后任务管理器 WebView2 渲染进程内存可见回落或停止增长；再开关一轮无泄漏趋势。

## 5. 风险与对策

| # | 风险 | 对策 |
| --- | --- | --- |
| 1 | 多标签下 3 个大文档并存，内存超限 | 标签上限 8；非激活标签只保留文档代理与状态，缩略图/索引按需重建；关闭即 destroy（验收第 6 条有读数判据） |
| 2 | 索引构建阻塞 UI（500 页） | 时间切片逐页构建 + 进度上报 + 随装载代际取消 |
| 3 | 选区→高亮矩形在缩放/旋转下错位 | 一律与画布同 viewport 换算，缩放只走 store 单一来源（技术方案风险 6 同源） |
| 4 | pdf-lib 矩形与 pdf.js 视口坐标系不一致 | 导出前用 `page.getSize()` + 页面旋转角统一换算；Acrobat/Chrome 双端目检兜底 |
| 5 | 反色滤镜大页掉帧 | 默认关闭，设置项开启；不作为默认阅读体验 |

- `develop` 分支施工，按批次提交（每批一组合规提交）。

# 百工·纸（Zhi）产品分析

> 对标 Adobe Acrobat · 2026-10-19 留档

## 要做什么

**核心职能**：PDF 全生命周期处理（打开即读、随手即改、多文件即合）。

**必备核心能力**：

- **查看阅读**：渲染、缩放、书签、全文搜索、批注高亮
- **页面组织**：旋转/删除/重排/提取
- **合并拆分**
- **基础编辑**：文本与图片增删改
- **格式转换**：PDF 与 Word/图片互转

**可后置高级能力**：OCR 扫描件识别、表单填写与制作、电子签名、安全（加密/水印/脱敏）、压缩、文档对比、AI 问答。

## 页面呈现样式

**主界面四区**：顶部上下文工具栏、左侧导航侧栏（缩略图/书签/注释）、中央文档视图、右侧任务面板。

**关键页面/模式**：

- **首页工具中心**：最近文件 + 功能入口聚合
- **阅读模式**：沉浸全屏、深色
- **编辑模式**：选中对象出属性面板
- **组织页面视图**：缩略图网格拖拽
- **独立工具向导页**：合并、OCR 等以"选文件→配置→执行→导出"任务流呈现

**交互范式**：单文档为主舞台、模式按需切换；工具采用向导式任务流；侧栏面板可折叠，阅读时隐、编辑时现。
